# Alex's Homelab
Personal infrastucture environment to go more indepth as to what happens behind the scenes when using Active Directory. 
Typically in most IT environments, applications like Toofit or Cayosoft are used to streamline processes like creating users, unlocking accounts, etc. 
I wanted to create a instance of Server 2022 in order to set up a server with AD installed. 

## Objectives

- Learn System Administration Practices
- Active Directory 
- How to join a machine to a domain
- Creating file shares
- Group Policy Management
